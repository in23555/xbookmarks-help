Bookmarks & quick notes

把收藏与灵感，
留在手边。

xbookmarks 是一个 Chrome 扩展。在普通网页顶部展开轻量收藏栏，整理文件夹、收藏当前页面、记录临时笔记，并按需备份到自己的 GitHub 仓库。

开始使用备份与同步了解数据处理

本页是帮助文档，不是在线收藏服务。使用基本功能无需注册账户或配置 GitHub。

01 / 第一次使用

  1. 安装扩展后，在 Chrome 扩展菜单中固定 xbookmarks 图标。
  2. 打开一个普通 HTTP / HTTPS 网页，点击插件图标或按 Alt+Z 展开收藏栏。
  3. 首次使用设置本地访问口令。这是当前浏览器的本地口令，不是网站登录账户。
  4. 点击五角星或按 Alt+X 收藏当前页面；再次操作可取消收藏。新收藏默认保存到根目录。

Chrome 内部页面、新标签页、扩展商店等受限制页面无法注入收藏栏，请换到普通网页使用。快捷键被其他程序占用时，可在 chrome://extensions/shortcuts 调整。

02 / 整理收藏

文件夹与级联菜单

点击收藏栏文件夹展开或收起；菜单内有内容的子文件夹可悬停展开。空文件夹也可以点击打开。

右键管理

右键收藏栏左侧空白区域新建根目录文件夹；右键文件夹可新建子文件夹、重命名或删除；右键书签可编辑或删除。

就地编辑与拖动

文件夹名称直接在原位置输入，回车或失焦保存。菜单内项目可拖动排序，根目录书签图标也可拖动调整位置。

收藏当前页面

点击星标后立即收藏，弹出的名称与位置可直接修改并自动保存，点击其他位置关闭。

03 / 速记与隐藏收藏

速记

每次打开速记会提供一条新草稿，空白草稿不保存。支持中文换行、#标签 筛选、两行折叠预览、展开编辑、复制与删除。速记跟随收藏一起参与本地备份和手动 GitHub 同步。

隐藏收藏夹

连续点击最左侧“所有”旁的文件夹图标三次，可进入隐藏收藏夹。首次使用需另设口令，且不能与主口令相同。隐藏收藏单独存放，但会与普通收藏一起导出和同步。

普通收藏、隐藏收藏和速记在上传或导出前统一使用登录口令加密。隐藏口令仅控制本地入口，不参与文件加密。本地浏览器存储仍为明文；新备份加密不会清除 GitHub 历史中的旧明文。

04 / 本地备份与 GitHub 同步

不使用云端也可以

设置中的“本地导出”生成 xbookmarks-时间戳.json，使用 AES-256-GCM 与 PBKDF2-SHA256（600,000 次）加密普通收藏、隐藏收藏和速记。“本地导入”先用当前登录口令解密、验证，再经确认替换数据。口令不匹配或文件损坏时不更改本地数据。如果云端仍是旧明文，请先从仓库下载文件，使用“本地导入”确认迁移，再“提交云端”覆盖；“拉取云端”只接受加密文件。旧版文件没有 notes 字段时保留已有速记。

连接自己的 GitHub

  1. 创建或选择你有写入权限的 GitHub 仓库，确保 main 分支存在。
  2. 创建 Fine-grained Personal Access Token，仅授权这个仓库的 Contents: Read and write。若组织要求审批，请先完成审批。
  3. 在扩展设置中填写你的仓库 URL 与 Token。仓库地址默认留空，并自动保存；Token 不保存，仅供本次同步使用，成功或失败后清空，关闭设置也不保留。旧版存储的 Token 会被移除。
  4. “提交云端”验证本地登录口令后，将完整数据加密为一个 JSON 文件，写到 main 分支的 data/bookmarks.json；“拉取云端”使用当前登录口令解密远端文件，成功后替换本地数据。

同步由你手动触发，不是自动合并。多设备使用时，应先拉取最新版本再修改并提交，避免覆盖。仓库没有备份文件时请先在有数据的设备提交一次。

口令校验记录、Token 和界面设置不会放入导出的收藏文件。不同设备须设置相同登录口令才能解密同一备份，隐藏口令可独立设置。新页面没有内存密钥时，首次备份操作会再次验证当前登录口令。修改登录口令后，请重新提交云端，并重新导出替换旧文件；旧备份不会自动改密，仍只能用旧口令解密。设置会保留醒目提醒，直到两项备份完成。

05 / 展示与锁定

点击图钉或右键插件图标选择“常态显示”，可在授权的网站自动显示收藏栏。开启时 Chrome 会请求网站访问权限；关闭后停止自动注入。

默认使用“推动页面”模式，为收藏栏预留位置；也可切换“覆盖展示”。支持浅色与深色皮肤。自动锁定默认 5 分钟，可选 5 / 15 / 30 / 60 分钟，也可随时点击锁定。

06 / 常见问题

口令忘记了怎么办？

没有邮件找回或后台恢复服务。加密备份必须用加密时的登录口令解密，设置一个新口令不能恢复旧备份。请自行保管口令；若当前仍能访问本地数据，先保留本地数据，不要清除或卸载。

清除本地数据会怎样？

会删除当前浏览器中的收藏、速记、两个口令记录和仓库地址。请先提交云端或本地导出。GitHub 上的文件不会随之删除；云端版本历史和下载过的备份需你自行管理。

同步失败？

检查仓库 URL、main 分支、Token 有效期和 Contents 权限，以及网络是否可访问 GitHub API。请勿在反馈中公开 Token、口令或真实收藏文件。

如何反馈？

到 公开反馈页面 新建 Issue，说明 Chrome 版本、扩展版本、复现步骤，以及问题是否与某个网站有关。反馈会公开显示，请先删除敏感信息。

English quick guide

xbookmarks adds a bookmark and quick-note toolbar to regular web pages. Set a local passphrase on first use. Alt+Z toggles the toolbar; Alt+X toggles saving the current page. Right-click folders to manage them. Local JSON backups and optional manual GitHub sync include normal bookmarks, hidden bookmarks and notes. GitHub setup is optional; enter your own repository URL and token. Backups are encrypted with the current login passphrase using AES-256-GCM and PBKDF2-SHA256. Use the same login passphrase on another device. After changing it, upload and export again to replace old backups. Hidden passphrases do not affect backup encryption. Tokens are never persisted and are cleared after each sync attempt. Local browser data remains unencrypted. See the English privacy summary.
