Privacy & data

隐私说明

适用于 xbookmarks Chrome 扩展 0.2.1。开发者 GitHub 账户：in23555。生效及更新日期：2026-11-12。

扩展默认在当前浏览器保存数据，不需要开发者账户，不接入开发者运营的收藏服务器、广告或分析 SDK。你可以自行选择向 GitHub 同步。

处理哪些数据

  • 收藏数据：你保存的网页 URL、标题、文件夹结构、图标图片数据或旧图标地址，以及创建与更新时间，包括隐藏收藏。
  • 速记：你主动输入的文本、从文本识别的标签和相关时间。
  • 连接配置：本地保存仓库 URL，其中可能包含 GitHub 用户名。Personal Access Token 仅保留在当前设置页面内存中，用于你发起的一次同步；无论成功或失败都会清空，关闭设置也会清空，不写入持久存储。旧版留下的 Token 会自动清理。
  • 本地安全与偏好：口令的盐值与 PBKDF2 校验记录、锁定状态、主题、展示方式与自动显示等设置。扩展不持久保存口令原文。
  • 当前标签页元信息：为了收藏页面及显示收藏状态，扩展读取当前或相关标签页的 URL、标题及图标地址；不会建立完整浏览历史记录。

扩展不读取网页正文、表单或键盘输入来分析用户，不用于广告、画像或跨网站追踪。你主动输入到速记的内容属于你的备份数据。

数据保存与传输

收藏、速记、仓库 URL、偏好和口令校验记录保存在浏览器扩展的本地存储中；解锁会话保存在浏览器会话存储中。它们不会因为安装扩展自动发送到开发者。

当你点击“推送云端”时，扩展经 HTTPS 直接访问 api.github.com，使用当前登录口令将普通收藏、隐藏收藏和速记加密为一个 JSON 文件，再写入你配置的仓库；“拉取云端”从该仓库读取密文，用当前登录口令解密，口令不匹配或密文损坏时不会覆盖本地数据。Token 在这些请求的 Authorization 请求头中发送给 GitHub，不写进收藏 JSON。GitHub 的处理由其 隐私声明 约束。

收藏网页时，扩展尝试从 Chrome 图标缓存或图标原地址读取图片，保存为 32×32 或 16×16 PNG 到收藏数据中，按 16px 显示，随加密备份迁移。旧备份仅有图标地址时不会自动转换，显示时仍可能向该网站请求图标或显示默认图标。

本地导出会创建一个加密 JSON 下载文件，内容包括隐藏收藏和速记，不包含口令校验记录或 Token。文件包含格式版本、PBKDF2 参数、随机盐、IV 和密文。使用 Web Crypto AES-256-GCM 与 PBKDF2-SHA256（600,000 次）；每次加密使用新盐和 IV。你自行决定是否分享该文件。

云端与导出文件已加密，本地浏览器存储仍为明文。登录口令用于备份加密，隐藏口令只控制本地入口。非可导出的密钥材料仅保留在当前页面内存中，锁定或关闭后清除，不发送或持久保存。新页面可能需要重新验证当前登录口令。改口令后必须重新推送、导出替换旧文件；旧备份仍需旧口令，遗忘后无法恢复。加密不会删除 Git 历史中的旧明文版本。

权限用途

权限用途
storage本地保存收藏、速记、连接配置、偏好和口令校验记录。
tabs读取相关标签页的 URL、标题和图标地址，收藏当前页、保存图标并识别收藏状态。
favicon读取 Chrome 缓存的网站图标，用于保存和显示书签图标。

api.github.com按你的操作直接提交或拉取指定仓库的数据。
可选 http / https 网站权限开启常态显示时用于自动注入收藏栏。你可以在 Chrome 扩展设置中撤销网站访问权限。

扩展不下载或执行远程 JavaScript。GitHub 返回的 JSON 作为数据解析，不作为代码运行。

保留、删除与控制

本地数据保留到你删除项目、清除扩展数据或卸载扩展。清除前请先备份；“清除本地数据”删除收藏、速记、口令记录与仓库地址。可在 GitHub 撤销 Token。

删除本地数据不会自动删除 GitHub 备份、Git 历史或你下载的文件。请到对应仓库和下载目录自行处理，第三方平台的备份保留规则由其决定。导入和拉取会替换数据，请先确认版本。

数据用途承诺

开发者不出售用户数据，不将其用于个性化广告，不将其转给数据经纪商，不用于信用评估或放贷。数据仅用于提供用户请求的收藏、速记、备份与同步功能。

xbookmarks 对从 Google API 接收的信息的使用和转移将遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

The use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

English privacy summary

xbookmarks stores bookmarks, folder structure, quick notes, preferences, the repository URL (which may include a GitHub username), and salted passphrase verifiers in the browser. It reads tab URLs, titles, and favicon URLs to save pages, capture icons, and show bookmark status. Bookmark data can include small PNG favicon snapshots or older favicon URLs. It does not persist a full browsing history, inspect page bodies or forms, or include advertising or analytics SDKs.

Manual GitHub sync sends your bookmarks (including hidden bookmarks) and notes directly to your chosen GitHub repository over HTTPS. Your token is kept only in the current settings page memory, is sent to GitHub for authentication, and is cleared after each sync attempt or when settings close. It is never persisted or included in backups; older persisted tokens are removed. When saving a bookmark, the extension may fetch its favicon image from Chrome cache or its original host and stores a 32×32 or 16×16 PNG snapshot in the encrypted backup, displayed at 16px. Older URL-only bookmarks are not converted automatically and may still request their original icon hosts or show a default icon. The developer does not receive an automatic copy of your data. No remote executable code is loaded.

Backups are encrypted with the current login passphrase using AES-256-GCM and PBKDF2-SHA256 (600,000 iterations), with fresh salts and IVs. Non-extractable key material is kept only in page memory until lock or close. Restore requires the same login passphrase; changing it requires uploading and exporting again. Old backups still require the old passphrase, with no recovery service. Hidden passphrases only protect the local UI. Local browser data remains plaintext, and old plaintext Git history is not removed. Delete local data in extension settings; remove GitHub files, history and downloaded backups separately. The developer does not sell data or use it for advertising, profiling, creditworthiness or lending. Contact: GitHub Issues. This documentation is hosted by GitHub Pages and has no analytics scripts. Effective November 12, 2026.
