Privacy & data

隐私说明

适用于 xbookmarks Chrome 扩展 0.2.0。开发者 GitHub 账户：in23555。生效及更新日期：2026-11-11。

扩展默认在当前浏览器保存数据，不需要开发者账户，不接入开发者运营的收藏服务器、广告或分析 SDK。你可以自行选择向 GitHub 同步。

处理哪些数据

  • 收藏数据：你保存的网页 URL、标题、网站图标地址、文件夹结构及创建与更新时间，包括隐藏收藏。
  • 速记：你主动输入的文本、从文本识别的标签和相关时间。
  • 连接配置：你填写的 GitHub 仓库 URL 与 Personal Access Token，用于你发起的 GitHub API 请求。
  • 本地安全与偏好：口令的盐值与 PBKDF2 校验记录、锁定状态、主题、展示方式与自动显示等设置。扩展不持久保存口令原文。
  • 当前标签页元信息：为了收藏页面及显示收藏状态，扩展读取当前或相关标签页的 URL、标题及网站图标地址；不会建立完整浏览历史记录。

扩展不读取网页正文、表单或键盘输入来分析用户，不用于广告、画像或跨网站追踪。你主动输入到速记的内容属于你的备份数据。

数据保存与传输

收藏、速记、配置和口令校验记录保存在浏览器扩展的本地存储中；解锁会话保存在浏览器会话存储中。它们不会因为安装扩展自动发送到开发者。

当你点击“提交云端”时，扩展经 HTTPS 直接访问 api.github.com，将普通收藏、隐藏收藏和速记作为一个 JSON 写入你配置的仓库；“拉取云端”从该仓库读取文件。Token 在这些请求的 Authorization 请求头中发送给 GitHub，不写进收藏 JSON。GitHub 的处理由其 隐私声明 约束。

显示书签图标时，浏览器可能向该图标地址所属的网站发送图片请求，对方可能收到通常的网络请求信息，例如 IP 地址和请求头。扩展不为此使用统一的第三方网站图标采集服务。

本地导出会创建一个由你保存的 JSON 下载文件，内容包括隐藏收藏和速记，不包含口令校验记录或 Token。你自行决定是否分享该文件。

收藏文件没有加密。隐藏口令和登录口令是界面访问限制，不是数据加密。公开 GitHub 仓库会公开其中的收藏文件；开发者无法替你控制仓库权限或收回已分享的备份。

可选 http / https 网站权限仅在开启“常态显示”时请求，用于页面加载时自动注入收藏栏。你可以关闭该功能或在 Chrome 扩展设置中撤销网站访问权限。

扩展不下载或执行远程 JavaScript。GitHub 返回的 JSON 作为数据解析，不作为代码运行。

保留、删除与控制

本地数据保留到你删除项目、清除扩展数据或卸载扩展。清除前请先备份；“清除本地数据”删除收藏、速记、口令记录与连接 Token。可在 GitHub 撤销 Token。

删除本地数据不会自动删除 GitHub 备份、Git 历史或你下载的文件。请到对应仓库和下载目录自行处理，第三方平台的备份保留规则由其决定。导入和拉取会替换数据，请先确认版本。

数据用途承诺

开发者不出售用户数据，不将其用于个性化广告，不将其转给数据经纪商，不用于信用评估或放贷。数据仅用于提供用户请求的收藏、速记、备份与同步功能。

xbookmarks 对从 Google API 接收的信息的使用和转移将遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

The use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

隐私或数据问题请通过 GitHub Issues 联系 in23555。请勿公开提交 Token、口令、敏感网址或完整收藏备份。发生数据处理方式变更时，会更新此页面日期与内容。

English privacy summary

xbookmarks stores bookmarks, folder structure, quick notes, preferences, GitHub connection settings, and salted passphrase verifiers in the browser. It reads tab URLs, titles and favicon URLs to save pages and show bookmark status. It does not persist a full browsing history, inspect page bodies or forms, or include advertising or analytics SDKs.

Manual GitHub sync sends your bookmarks (including hidden bookmarks) and notes directly to your chosen GitHub repository over HTTPS. Your token is sent to GitHub for authentication and is excluded from the backup JSON. Favicon loading may send ordinary image requests to the icon's host. The developer does not receive an automatic copy of your data. No remote executable code is loaded.

Backups are plaintext. Local passphrases are access barriers, not encryption. Public repositories make their files public. Delete local data in extension settings; remove GitHub files, history and downloaded backups separately. The developer does not sell data or use it for advertising, profiling, creditworthiness or lending. Contact: GitHub Issues. This documentation is hosted by GitHub Pages and has no analytics scripts. Effective November 11, 2026.
